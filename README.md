# 🥗 FOOD NUTRIENTS DATA ANALYSIS

A Python data analysis project focused on cleaning, exploring, and visualizing nutritional datasets (`nutrients_csvfile.csv`). Designed to uncover key patterns in food composition, calorie distribution, and macro-nutrient profiles.

---

## 📌 KEY FEATURES

* **Data Cleaning & Preprocessing:** Parsing numerical features, handling missing values, and standardizing data formats.
* **Exploratory Data Analysis (EDA):** Statistical summaries and distributional checks across nutrient groups.
* **Data Visualization:** Visualizing distributions and relationships between calories, proteins, fats, and carbohydrates.

---

## 🛠️ BUILT WITH

* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
